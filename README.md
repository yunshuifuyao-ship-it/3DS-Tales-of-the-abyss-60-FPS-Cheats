# 3DS-Tales-of-the-abyss-60-FPS-Cheats
Cheats For Tales of the  abysss 3D，use with CFW Luma. This project is just for learning and research.
- 在汉化版（日版）和英版中测试，目前效果还是不错的，在一个限制30帧的游戏引擎实现了60帧的效果，且不会让游戏运行时间暴走，至于会不会影响剧情动画有待测试
- 至于行走速度，目前是30帧的1.4倍（PS2同理），貌似进一步缩放会让角色跑步动画丢失变成走路（游戏通过帧率判定动画阀值）
- 金手指代码上参考了PS2现有的60帧金手指，两个可执行程序其实底层特别相似，3DS这边还需要单独对动画播放系数进行缩放处理
- 英版是直接对日版金手指对应偏移加固定值的暴力移植，理论功能应该跟日版一致，暂时不打算制作欧版的金手指，如有需要可以自行移植
